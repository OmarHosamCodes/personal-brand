# Omar Hosam portfolio hyperframes

Animated 1:1 product showcases for the Selected work grid (Astro iframes).
Generated in Open Design project `portfolio-hyperframes`. See `projects-brief.md` for the contract.

## Artifacts

- `frame-ogm-reimagined.html` — Tribe IT (community Home → Learn → Live → Admin Command Center)
- `frame-brainiac.html` — Orch (Canvas → agent proposal → Agency tracker)
- `frame-atoms.html` — Atoms Academy (Topics → Lecture → Homework → Exam, RTL)

Each HTML file is self-contained, square, autoplays a ~13s loop, and freezes under `prefers-reduced-motion`.
Served from `public/frames/{ogm-reimagined,brainiac,atoms}.html`.
