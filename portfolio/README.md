# Omar Hosam — Portfolio

Dark-default one-pager for founders: freelance, consultation, and training.

Stack: Astro 7, React islands, Tailwind v4, shadcn/ui. Brand: Creator Broadcast Pipeline (kinetic orange).

## Commands

| Command | Action |
| --- | --- |
| `bun install` | Install dependencies |
| `bun dev` | Dev server |
| `bun build` | Static build to `dist/` |
| `bun preview` | Preview production build |
| `bun run self-check` | Contrast + content freeze checks |

## Structure

- `src/content/site.ts` — content freeze
- `src/pages/index.astro` — marketing one-pager
- `src/pages/system.astro` — design system showcase
- `docs/` — content freeze, growth/CW audits, OD hero comps
- Domain target: `omarhosamcodes.com` (host undecided)

## Open Design

Hero A/B/C comps live under `docs/od-heroes/` (winner: **B**). Project hyperframes are generated in Open Design project `portfolio-hyperframes`.
